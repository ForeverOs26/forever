# FOREVER-EXIT-001 — Owner decision record

Status: Owner-approved durable strategic decision  
Date: 2026-08-03  
Authority: Owner

## Decision

Forever adopts `FOREVER-EXIT-001` as the strategic direction for post-purchase ownership continuity, off-plan assignment and resale.

Forever will build **a way out of a property**, not an open listing board.

The first public transaction product is a mandate-backed exit offer for a specific unit, shown inside the project/unit context and matched to buyer demand already known to Forever.

## Product boundaries

- Assignment is the first priority scenario.
- Resale is supported as a distinct listing kind after title transfer.
- A specific owner exit offer requires a valid signed mandate.
- The mandate requirement is not a secondary approval gate for developer projects and does not modify `docs/FOREVER_OWNER_DIRECT_PUBLICATION_POLICY.md`.
- Project catalogue publication remains Owner-direct and fast.
- Owner identity, mandate, SPA, payment evidence, FET, title, quota evidence and comparable sensitive files remain private.
- Forever does not hold client money.
- Forever does not sell leads, open a public unverified owner marketplace, build an MLS, become an iBuyer, or introduce a paid verification badge.

## Product improvement adopted

Assignment Desk becomes the first transaction lane inside a broader **Forever Ownership & Exit Loop**:

```text
buyer↔unit Ownership Record
→ private Exit Intent
→ signed Mandated Exit Offer
→ demand-first Exit Match
→ Exit Passport / transaction
```

This creates value for existing clients and a repeat/referral acquisition loop without delaying the 100+ project catalogue.

## Immediate consequences

The following begin as non-code operating work:

1. internal buyer↔unit register for past and future Forever transactions;
2. Thai-lawyer-reviewed mandate template;
3. one manual assignment or resale case from beginning to end;
4. private demand log by project/unit profile;
5. DPO, RoPA and notice-and-takedown operating confirmation.

The following remain the immediate product priority and must not be delayed:

- Coralina production recovery;
- stable ordinary Studio publication;
- `FOREVER-STUDIO-FAST-PROJECT-ONBOARDING-001`;
- 20 → 50 → 100+ Owner-selected projects.

Exit v1 product code begins only after ordinary Studio publication is stable and the manual transaction has produced legally viable workflow evidence.
